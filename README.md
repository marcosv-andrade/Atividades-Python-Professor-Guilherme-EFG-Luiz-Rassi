# 🐍 Atividades de Programação Orientada a Objetos

Repositório destinado às atividades, exercícios e exemplos desenvolvidos na disciplina de **Programação Orientada a Objetos** com o professor Guilherme na **Escola do Futuro do Estado de Goiás Luiz Rassi**.

---

## 📚 Sobre

Este repositório reúne os exercícios práticos desenvolvidos ao longo das aulas. O objetivo é registrar o aprendizado prático em Python, iniciando pela consolidação da lógica e estruturas fundamentais da linguagem para posterior aplicação na construção e modelagem de classes, objetos, atributos e métodos.
